## 一、项目概述

### 1.1 项目背景
高校社团管理系统是一个基于Vue 3 + .NET Web API + SQL Server的现代化社团管理平台，旨在提升高校社团管理效率，实现社团活动的信息化管理。

### 1.2 核心功能
- 用户管理（注册、登录、权限管理、批量操作）
- 社团管理（创建、审核、注销、部门管理）
- 成员管理（加入申请、审批、角色分配、导出）
- 活动管理（创建、审核、报名、扫码签到、总结）
- 财务管理（经费申请、审批、报表、预算）
- 评价系统（活动评价、社团评分、意见反馈）
- 通知公告、文件上传、数据统计、操作审计日志

### 1.3 关键特性要求
- **用户角色体系**：超级管理员、普通管理员、社团主席、副主席、部门主席、部长、部员、访客（8种角色）
- **注册方式**：邮箱注册、手机号注册、校园统一认证、第三方OAuth授权
- **移动端优化**：底部导航、响应式布局、拍照上传支持
- **数据安全**：JWT认证、密码哈希、登录失败锁定、操作审计日志
